A blog static site built with [Sveltepress](https://sveltepress.site/) and its blog theme [@sveltepress/theme-blog](https://www.npmjs.com/package/@sveltepress/theme-blog). Until November 2026 it was a VuePress 1 site; the old sources are kept in `docs/`.

## Online Demo

[My blog site](https://dongsheng-blog.netlify.app/)

## Install

```sh
pnpm install
```

## Dev

```sh
pnpm dev   # http://localhost:23456
```

## Build

```sh
pnpm build   # output in dist/, search index by pagefind
```

Netlify builds with `pnpm build` and publishes `dist/` (see `netlify.toml`).

## Layout

* `src/posts/*.md` - posts (including 我的开源 `category: project` and 健身随记 `category: fitness`)
* `src/demos/` - Svelte components used inside posts
* `src/routes/listen/`, `src/routes/friend-links/` - 听听歌吧 and 友情链接 pages
* `src/lib/ValineComments.svelte` - Valine comments (same LeanCloud app as the old site)
* `static/_redirects` - old VuePress URLs → new URLs, generated by `scripts/gen-redirects.mjs` from the routes the old site served

## songs

The player on `/listen/` reads `songs/songsInfo.json`. `songs/songs.yml` is the source list for the old fetch script `songs/index.js`:

* `songUrl` - The song asset url, file in `static/songs/`
* `songId` - The music.163.com music id
* `customLyrics` - Determine whether to use custom lyrics. If set to `true`, `lyrics` should be set
* `lyrics: Array<[number, string]>`  
  Two dimension array  
  Every item should contain a number and a string  
  Number is the seconds of the lyrics content shown time  
  String is the lyrics content  
  Check the songs/songs.yml file for full example
